\begin{frame}{Glossary: branches, local events, and refinement}
\scriptsize
\begin{description}
  \item[Residual] $F(U,p)$ evaluated at a proposed solution; its norm measures equation defect.
  \item[Branch] one connected family of roots $F(U,p)=0$.
  \item[Fold] a regular turning point where the state Jacobian is singular.
  \item[Hopf] an equilibrium point where a complex-conjugate eigenvalue pair crosses the imaginary axis.
  \item[Pseudo-arclength] continuation that corrects $(U,p)$ under an added local curve-distance constraint.
  \item[$l_1$] first Lyapunov coefficient: locally supercritical if negative,
        subcritical if positive, and degenerate-candidate near zero under the chosen tolerance.
  \item[Codimension] number of independent conditions, and generically free parameters, needed for an event.
  \item[CP / BT] cusp: degenerate fold; Bogdanov--Takens: double zero eigenvalue with non-degeneracy conditions.
  \item[GH / ZH / HH] generalized Hopf: $l_1=0$ at Hopf; zero--Hopf: zero plus imaginary pair;
        double--Hopf: two distinct imaginary pairs.
  \item[Implicit differentiation] derivative of a converged equation $G(x^*,\theta)=0$ via
        $dx^*/d\theta=-G_x^{-1}G_\theta$, not reverse-mode replay of solver iterations.
\end{description}
\end{frame}

\begin{frame}{Glossary: periodic orbits, phase, and stored results}
\scriptsize
\begin{description}
  \item[Collocation] a finite root system formed by enforcing the ODE at points of piecewise polynomials.
  \item[Phase condition] one scalar equation that removes a periodic orbit's arbitrary time shift.
  \item[Floquet multiplier] eigenvalue of the one-period linearized map; nontrivial multipliers diagnose cycle stability.
  \item[PD] period-doubling candidate: a real nontrivial multiplier crosses $-1$ under detector conditions.
  \item[NS] Neimark--Sacker candidate: a complex-conjugate nontrivial pair crosses the unit circle under detector conditions.
  \item[iPRC] infinitesimal phase-response curve $Z(t)$: first-order phase sensitivity along a stable cycle.
  \item[dPRC] JaxCont's total parameter derivative $dZ/dp$, including the reconverged orbit's change with $p$.
  \item[Validity mask] boolean selector for real points within a fixed-size traced result buffer.
\end{description}

\begin{alertblock}{Conventions are part of the quantity}
Phase origin, normalization, units, nontrivial-multiplier filtering, and the
meaning of ``dPRC'' must be aligned before comparing results.
\end{alertblock}
\end{frame}

\begin{frame}{Main takeaways}
\small
\begin{enumerate}
  \item Continuation follows connected roots; it is neither time simulation nor disconnected-branch discovery.
  \item Pseudo-arclength can pass ordinary folds by correcting state and parameter together.
  \item Equilibrium eigenvalues and periodic Floquet multipliers answer different stability questions.
  \item Hopf and codimension-two refinements classify supplied candidates; they do not switch branches or trace two-parameter curves.
  \item Fixed buffers make whole-branch JIT and batching possible; read eager results with \texttt{n\_valid} and traced results with their mask/count.
  \item Begin with a trustworthy seed, inspect numerical health, repeat, then seek independent evidence.
\end{enumerate}

\end{frame}

\begin{frame}{Appendix: natural versus pseudo-arclength}
\small
\begin{center}
\begin{tabular}{p{.24\textwidth}p{.32\textwidth}p{.32\textwidth}}
\toprule
 & Natural & Pseudo-arclength\\
\midrule
Corrected unknown & $U$ at fixed $p$ & $(U,p)$\\
Predictor & $p+\operatorname{sign}(p_{\rm end}-p)\,ds$ & $(U,p)+ds\,t$\\
Newton matrix & $F_U$ & $\begin{bmatrix}F_U&F_p\\t_U^T&t_p\end{bmatrix}$\\[3mm]
At an ordinary fold & $F_U$ singular; stalls & bordered system usually regular\\
Stored tangent & zero-filled shared buffer & normalized branch tangent\\
Engine name & \texttt{natural\_scan} & \texttt{pseudo\_arclength\_scan}\\
\bottomrule
\end{tabular}
\end{center}

\begin{block}{Shared contract}
Both engines use fixed buffers of length \texttt{max\_steps + 1}, count
accepted points with \texttt{idx}, and return the initial point plus accepted corrections.
\end{block}
\end{frame}

\begin{frame}{Appendix: scalar cubic fold derivation}
For
\[
F(u,p)=p+u-u^3/3=0,
\]
the branch is $p(u)=u^3/3-u$. Its tangent in the parameter direction vanishes when
\[
\frac{dp}{du}=u^2-1=0
\quad\Longrightarrow\quad u=\pm1.
\]
Hence
\[
(u,p)=(-1,2/3),\qquad(1,-2/3).
\]
The state Jacobian is the scalar $F_u=1-u^2$, so it vanishes at exactly the
same two points. Natural correction fixes $p$ and encounters this singular
Jacobian; pseudo-arclength adds the tangent constraint and can follow the turn.
\end{frame}

\begin{frame}[fragile]{Appendix: accepted-point engine pseudocode}
\begin{lstlisting}
allocate P, Q, T, C, D with max_steps + 1 slots
store initial point in slot 0; idx = 0

while idx < max_steps and not stop:
    predicted = accepted + ds * tangent
    candidate, converged, iters = correct(predicted)
    candidate_tangent = tangent_at(candidate)  # always computed
    write = idx + 1
    buffers[write] = where(converged, candidate, old_slot)
    accepted = where(converged, candidate, accepted)
    tangent = where(converged, candidate_tangent, tangent)
    idx = idx + int(converged)
    ds = adapt(ds, iters, converged)  # rejection shrinks ds
    stop = reached or (not converged and ds <= ds_min) or nonfinite

return fixed_buffers, n_valid = idx + 1
\end{lstlisting}
\begin{alertblock}{Budget semantics}
\texttt{max\_steps} budgets accepted points after the initial point.
A rejected correction leaves \texttt{idx} unchanged, adds computation, and
shrinks \texttt{ds}; it does not consume the accepted-point budget.
\end{alertblock}
\end{frame}

\begin{block}{Why fixed fields matter}
Every loop iteration returns the same PyTree structure and array shapes, so
JAX can compile the bounded dynamic loop and batch independent runs.
\end{block}
\end{frame}

\begin{frame}{Appendix: branch-free selection, bounded control}
\small
\begin{columns}[T,onlytextwidth]
\column{.48\textwidth}
\begin{block}{Array selection inside one attempt}
\begin{itemize}
  \item compute the candidate tangent even if correction failed;
  \item use \texttt{jnp.where} for buffer writes and accepted state;
  \item advance \texttt{idx} by the boolean convergence value;
  \item retain the prior accepted point after rejection.
\end{itemize}
\end{block}
\column{.48\textwidth}
\begin{block}{Compiled loop control}
\begin{itemize}
  \item the outer primitive is \texttt{lax.while\_loop};
  \item its condition is \texttt{idx < max\_steps} and not \texttt{stop};
  \item stop combines endpoint, stalled-at-\texttt{ds\_min}, and non-finite checks.
\end{itemize}
\end{block}
\end{columns}

\begin{alertblock}{What ``scan'' means here}
\texttt{natural\_scan} and \texttt{pseudo\_arclength\_scan} are historical
engine names for a bounded branch sweep. Neither function uses \texttt{lax.scan}.
\end{alertblock}
\end{frame}

\begin{frame}{Appendix: eager and traced results reassemble differently}
\scriptsize
\begin{columns}[T,onlytextwidth]
\column{.48\textwidth}
\begin{block}{Eager call}
\begin{enumerate}
  \item concretize \texttt{n = int(res.n\_valid)};
  \item trim states, params, and tangents to \texttt{[:n]};
  \item compute requested stability and eager event detection;
  \item build \texttt{ContinuationSolution}, then \texttt{ContinuationResult};
  \item \texttt{branch.valid is None}; plotting has an underlying solution.
\end{enumerate}
\end{block}
\column{.48\textwidth}
\begin{block}{Inside \texttt{jit}/\texttt{vmap}}
\begin{enumerate}
  \item \texttt{n\_valid} cannot become a Python integer;
  \item retain full fixed-size buffers;
  \item set \texttt{branch.valid = arange(buffer\_len) < n\_valid};
  \item store the true count in \texttt{result.stats["n\_valid"]};
  \item reject non-empty \texttt{events}; \texttt{\_solution=None}, so eager plotting is unavailable.
\end{enumerate}
\end{block}
\end{columns}

\begin{alertblock}{Do not use traced padding as data}
In traced results, \texttt{branch.n\_valid} is the buffer length because it is
derived from array shape; use the validity mask or \texttt{stats["n\_valid"]}.
\end{alertblock}
\end{frame}
