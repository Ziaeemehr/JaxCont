\begin{frame}{What you should be able to explain afterwards}
\begin{enumerate}
  \item What a continuation method computes-and why it is not time integration.
  \item Why natural parameter continuation fails at a fold.
  \item How pseudo-arclength prediction and correction pass a fold.
  \item How the same engine follows equilibria and collocated periodic orbits.
  \item How eigenvalues, Floquet multipliers and event tests reveal stability changes.
  \item What automatic differentiation, JIT, \texttt{vmap}, PyTrees and custom VJPs contribute.
  \item How branch diagrams and 2D phase planes answer complementary questions.
  \item How to plan, run, validate, visualize and interpret a continuation study.
\end{enumerate}
\begin{alertblock}{Important naming clarification}
The function contains ``scan'' in its name, but its outer loop is currently
implemented with \texttt{jax.lax.while\_loop}, not \texttt{jax.lax.scan}.
\end{alertblock}
\end{frame}

\begin{frame}{What is new on current main after v0.2?}
\small
\begin{columns}[T]
\column{.49\textwidth}
\begin{block}{A composed 2D phase plane}
\begin{itemize}
  \item nullcline contours;
  \item normalized vector fields or streamlines;
  \item every continued equilibrium at a chosen parameter;
  \item integrated or precomputed trajectories;
  \item one \texttt{plot\_phase\_plane} convenience layer.
\end{itemize}
\end{block}
\column{.49\textwidth}
\begin{block}{Why this changes the workflow}
A bifurcation diagram says how solutions change with a parameter. A phase
plane freezes one parameter and shows the local state-space geometry behind
that branch point.
\end{block}
\begin{alertblock}{Release status}
These functions are in the changelog's \emph{Unreleased} section. The installed
package version is still 0.2.0; use a current source checkout until the next
release.
\end{alertblock}
\end{columns}
\end{frame}

\begin{block}{Unifying principle}
The continuation engine only needs a pure residual with matching input and output shapes.
The problem factory decides whether that residual represents one equilibrium or one complete orbit.
\end{block}
